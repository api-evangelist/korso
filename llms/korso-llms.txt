# Korso

> Korso is a Los Angeles based company (Y Combinator Spring 2026) building tooling for the next
> generation of software. Its flagship open source product, Shepherd, is a coordination layer for AI
> coding agents: a Fastify + Postgres hub, a published stdio Model Context Protocol server
> (@korso/shepherd), a shared zod wire contract, and an auth-agnostic React dashboard
> (@korso/shepherd-ui). Shepherd lets a fleet of agents working across sessions, worktrees, and team
> members claim files, release claims, broadcast announcements, and read a shared workspace landscape
> so they stop producing merge conflicts and overwriting each other. Korso also runs a beta Trading API
> over its own quantitative trading desk, and Korso Research, an AI-native research workspace.

Generated by the API Evangelist enrichment pipeline on 2026-07-19. Korso publishes no llms.txt of its
own (https://korsoai.com/llms.txt returned 404) and no OpenAPI document; the Model Context Protocol
tool surface is the public API surface.

## MCP tools

- [work](https://korsoai.com/docs/mcp-tools/work): Claim the files or task area an agent is about to work on. Returns a workItemId.
- [done](https://korsoai.com/docs/mcp-tools/done): Release a Shepherd work claim by workItemId.
- [announce](https://korsoai.com/docs/mcp-tools/announce): Send a workspace announcement or direct message to another agent.
- [sync](https://korsoai.com/docs/mcp-tools/sync): Refresh the current workspace landscape (claims, announcements, presence).
- [link](https://korsoai.com/docs/mcp-tools/link): Opt a repository into coordination via a committed .shepherd marker.
- [unlink](https://korsoai.com/docs/mcp-tools/unlink): Opt a repository out of coordination, removing the marker.
- [decline](https://korsoai.com/docs/mcp-tools/decline): Opt out locally for one user, without ever writing a marker.

## Notes

- Authentication is a bearer token in the MCP server environment: SHEPHERD_TOKEN (account-scoped,
  `shp_` prefix, Korso-hosted) or TEAM_TOKEN (shared workspace-wide secret, self-hosted). At least one
  is required at startup. There is no OAuth surface and therefore no scopes.
- Shepherd publishes no webhooks, no AsyncAPI, no gRPC, no sandbox, and no status page.
- No .well-known documents are served on korsoai.com.
- korsoai.com is a single-page app that returns HTTP 200 with a sign-in shell for any unknown path;
  a bare 200 is not evidence that a page exists.
